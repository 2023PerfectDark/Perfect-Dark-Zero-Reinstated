PERFECT DARK ZERO: REINSTATED - RELEASE VALIDATION
Release v124 - 27 October 2026
TU3 base 1.8; game build v124

DIALOG MOUSE CONTROLS v124
OK and Cancel use the native controller-button path. Dismissed dialogs are
validated against live UI handles so they cannot block later mouse input.
The user confirmed both dialog actions and subsequent menu hovering/clicking.

REV 1 INSTALLER SUPPORT v124
The US Rev 1 ISO is recognized independently of the original US disc.
Original-disc acceptance and regional language validation still pass.
A complete separate installation from the clean Rev 1 extraction passed
file validation and reached the in-game main menu / local mode selection.
Rev 1 has added files for both map packs (six maps). The user reported a DLC map reaching gameplay in the separate test install.
This is not an exhaustive test of all six maps.
The Rev 1 image reader never executes guest game code. A small binary delta
converts its verified loaded image into the supported TU3 executable image.
The resulting XEX was independently loaded and its entire image matched TU3.
Exact source/output hashes, helper integrity, payload selection and corrupt
or truncated delta rejection have been tested. These checks do not prove
that every mission, map or gameplay action is compatible with Rev 1 assets.
The original ISO/extracted source and existing installs are not changed.

PLAYER-LIST HIGHLIGHTS v123
Fixes stale gamertag highlights in the multiplayer lobby and Connected
Players screen. The user confirmed both screens highlight one name at a
time in the installed build. Targeted host tests cover visual reset,
selection changes, scrolling/recycled rows, and disabled rows; these
tests do not replace broader in-game keyboard/click testing.
Random bot head/body buttons remain a separate unresolved issue.

UPDATER AND PACKAGING v121
The installer now includes its update source configuration and targets
2023PerfectDark/Perfect-Dark-Zero-Reinstated. Only compatible TU3 update
packages are accepted. Older retail packages cannot replace this build.
Updated assets on the installer release are identified by their SHA256
digest and upload time, even when the release tag stays the same.
The gameplay limitations documented below remain.

CURRENT AUTOMATED CHECKS
All six regression runners passed during this release preparation:
- 15 host behavior tests: reload timing, physics timing, input logic,
  breathing motion, NPC placement, Nightclub suspicion, MP progression,
  mission summary, debug position, cheat progress, campaign logic,
  Perfect Dark Zero mode, co-op ally logic, co-op synchronization,
  and Surface mission policy.
- Native animation sampler and holster stability, including 10,000 cache
  selections with no live-graph eviction. Owner/model changes and cache

- Model palette lifetime and material-table guards. Harnesses reproduce
  the old stale-memory overwrite and verify the corrected scope.
- Manual Reload's automatic-reload and Fire-button gates.
- Blink timing at 30/60/120/240/360 FPS, including native cover handling.
Host tests do not prove all native resource lifetimes or gameplay behavior.

RUNTIME EVIDENCE
The user confirmed Surface boxes and the three native red barrels.
The v117 Klobb crash was captured at the native CMP150 record initializer
with a missing model. The corrected loader preloads the donor package,
checks availability, and holds its package lease through weapon cleanup.
The later v119 trace records Klobb weapon ID 39 and reload playback.
The v119 monitored process exited with code 0.
The v120 monitored run reached multiplayer gameplay and exited normally
with code 0. It does not establish solo holster stress-test coverage.
Manual Reload and third-person/cover blinking were user-confirmed working.

HOLSTER LIMITATIONS
Resident cosmetic copies are hidden on equip/drop or when the feature is
turned off. Native parent teardown owns destruction. The 13-entry cache
omits new cosmetic copies when full instead of evicting a live graph.
The DEF-12 shotgun cosmetic holster remains excluded. Earlier material
corruption and GPU device-hung incidents are not all proven resolved by
this change. Solo pickup/switching and mission-transition tests remain.

PAYLOAD AND DEFAULTS
The TU3 payload matches the compiled v123 executable. Packaging verifies
all manifest sizes/hashes, artwork paths, destination uniqueness and ZIP CRC.
Surface v4 terrain, pickup geometry, music, supporting textures and the
native red-barrel package are mandatory packaging checks.
Fresh installations keep unlock-all disabled, walking speed at 20%, and
runtime debugging off. Existing player installations are not overwritten.
Only four reviewed optional shareable shader files are bundled under user/;
no personal settings, saves, logs, crash dumps or debug symbols are included.
The download folder contains only PDZ Setup.exe, README.txt and VALIDATION.txt.

it is not a new full game install or cross-GPU performance benchmark.

Automatic climbing, weather area boundaries and Mission 1 ending rain need
broader playthrough coverage. Bonus DVD physical controller use and a clean

renderer, hardware configuration or of crash-free gameplay.
